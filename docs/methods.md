# 方法与数据口径

本图集是**数据叙事**，不是测绘成果，也不是产业统计年报。所有换算、示意和口径冲突处理都写在这里。

## 1. 范围

研究对象为云南省迪庆藏族自治州德钦县境内澜沧江、金沙江干热河谷的葡萄种植带。页面回答三个问题：

1. 葡萄园在海拔上分布在哪里、对应的热量条件大致如何；
2. 公开报道中的种植面积为何互相矛盾、各口径差多少；
3. 品种、土壤与时间线分别有什么可核查的公开来源。

## 2. 面积口径与冲突处理

德钦县葡萄面积在公开材料中有四种口径：

| 口径 | 数值 | 换算为亩 | 来源 |
|---|---|---|---|
| 2022 年省农业农村厅典型案例 | 1.38 万亩 | ≈13800 | S1 |
| 2024 年新华网转载迪庆发布 | 6867 亩 | 6867 | S2 |
| 2024 年迪庆州农业农村局答复 | 6418.66 亩 | 6418.66 | S3 |
| 2025 年 Wineinfo 报道 | 近 7000 亩 | ≈7000 | S7 |

处理原则：

- **四种口径同屏并列**，不取平均、不合并为一个“权威值”。同年两个数值相差约 6.5%，差异可能来自统计时点、地块认定标准（成园 / 含新植）或转写误差，公开材料不足以判定。
- 万亩按 `1 万亩 = 10000 亩` 换算，展示时保留原文“近”“约”等限定词。
- 迪庆州 2024 年全州值 10557.96 亩只作参照，其中德钦 6418.66 亩、香格里拉 161.3 亩、维西 3978 亩，不把全州值算作德钦的第五种口径。
- 产量数据只使用明确注明吨的单位，不与面积混算单产。

## 3. 海拔—温度换算

页面用环境气温直减率做**示意换算**：

```
T(h) = T_base − 6.5 × (h − 2200) / 1000
```

- `T_base = 20 °C`，基准海拔 `2200 m`；
- 直减率取 `6.5 °C/km`，是标准大气的近似值；
- 海拔定义域钳制在 1600–3100 m；
- 结果保留一位小数。

这是“同一气团随海拔抬升冷却”的静力近似，不包含逆温、坡向、谷风、云量与水体调节。真实园地温度必须用园区气象站或再分析数据校验。

## 4. 成熟带划分

| 海拔 | 标签 | 说明 |
|---|---|---|
| < 2000 m | 早熟带 | 热量相对充足，夏季高温与干旱是主要压力 |
| 2000–2500 m | 中熟带 | 赤霞珠主栽带，需权衡成熟窗口与秋雨、早霜 |
| > 2500 m | 晚熟带 | 热量不足风险上升，需要更长挂树期与更严的园地选择 |

阈值是产业经验的分段，不是品种积温模型；同一品种在不同年份可能跨带。

## 5. 地图的示意性质

- 河谷线、村庄点位**不按经纬度投影**，只保留上下游与左右岸的相对关系；页面上标注“示意”。
- 等高线是装饰性背景，不参与任何计算。
- 村庄海拔取公开材料中的范围与代表值，范围端点来自多来源交叉，非实测。
- 需要精确边界时应改用行政区划矢量与 DEM，而不是本页 SVG。

## 6. 来源与检索

- 每条数据行携带 `source_id`，`data/sources.csv` 给出标题、发布者、日期、链接与检索日期。
- 链接失效时保留标题与检索日期，便于按标题回溯；页面不隐藏失效来源。
- 冲突口径的来源必须同时保留，不允许只留下“看起来最合理”的一个。

## 7. 局限

1. 面积口径没有官方统一台账，四值并列只是把分歧摊开。
2. 温度换算是静力近似，不能替代园地实测；逆温谷地会显著偏离。
3. 村庄点位为示意，不能用于地块定位或面积量算。
4. 品种与土壤信息来自公开报道，覆盖不完整，未做田间核实。
5. 时间线只收录可公开检索的事件，不代表产业全貌。
6. 页面无后端，数据更新需要重新构建并跑测试。

## 8. 复现

```bash
npm ci
npm test
npm run build
npm run serve
```

构建脚本把 CSV 汇总为 `data/bundle.json`；测试校验字段、单位白名单、来源存在性、海拔顺序与页面约束。
